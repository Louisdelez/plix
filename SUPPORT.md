## Community Support

### GitHub Discussions

For general questions and community discussion:

**[GitHub Discussions](https://github.com/Louisdelez/plix/discussions)**

Use the appropriate category:
- **Q&A** - Technical questions about using Plix
- **Ideas** - Feature suggestions and brainstorming
- **Show and Tell** - Share your mods, servers, or creations
- **General** - Anything else related to Plix

### GitHub Issues

For bug reports and feature requests:

**[GitHub Issues](https://github.com/Louisdelez/plix/issues)**

Before opening an issue:
1. Search existing issues to avoid duplicates
2. Include relevant information (version, OS, logs)
3. Use the provided issue templates

## Bug Reports

When reporting a bug, please include:

1. **Plix version**: Run `plix-client --version` or `plix-server --version`
2. **Operating system**: Windows 10/11, Ubuntu 22.04, macOS 14, etc.
3. **Steps to reproduce**: Detailed steps to trigger the bug
4. **Expected behavior**: What should happen
5. **Actual behavior**: What actually happens
6. **Logs**: Relevant log output (use code blocks)
7. **Screenshots**: If applicable

## Security Issues

**DO NOT report security vulnerabilities through GitHub Issues.**

Please see [SECURITY.md](SECURITY.md) for our security policy and how to report vulnerabilities responsibly.

## Commercial Support

Plix is an open-source project maintained by volunteers. Commercial support is not currently available.

For enterprise deployment questions, open a GitHub Discussion in the General category.

## Response Times

As an open-source project:

- **GitHub Issues**: Triaged within 1 week
- **GitHub Discussions**: Community-driven, responses vary
- **Security Reports**: Acknowledged within 48 hours (see SECURITY.md)

## Tips for Getting Help

1. **Be specific**: Include version numbers, error messages, and context
2. **Search first**: Your question may already be answered
3. **Provide examples**: Minimal reproduction cases help us help you
4. **Be patient**: Maintainers and community members volunteer their time
5. **Help others**: Once you learn something, share your knowledge
